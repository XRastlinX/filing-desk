# Contributing

A change lands only if the act, the object, and the condition still match.

Run `python3 examples/show.py` before you open a pull request. elegxis onto elegxis must land. biaschisis onto leiorrhoe must refuse.

Do not add a commit hook. Do not add a validator that aborts a commit. A red check is a record. The merge stays with the maintainer.

Do not change a standing in order to make a filing land.
